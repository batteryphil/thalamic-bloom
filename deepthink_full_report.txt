SECTION 2: THE CRITICAL PATH TO THE COGNITIVE BLOOM
================================================================================

This section documents the complete engineering history of how the Bloom was
achieved, including a critical architectural failure that was discovered and fixed.

2.1 — THALAMIC PRIMER ZERO-INIT GRAFT (Phase 3 Start, Step ~22,200)
  A new MambaLayer ("Thalamic Primer") was surgically grafted before the MIMO
  routing gate with its output projection initialized to all zeros. This created
  a perfect Identity Pass-Through that preserved the Phase 2 SFT weights while
  giving the routing gate a new, trainable temporal context signal to grow into.

2.2 — THE ENTROPY GLASS CEILING (Discovery, Steps 22,200–26,200)
  The original routing gate formula was:
    gate_score = sigmoid(entropy - 2.0)
    
  Where entropy was computed from early logits BEFORE the 24-layer backbone:
    early_logits = F.linear(x, self.embedding.weight)
    entropy = -(probs * log(probs + 1e-9)).sum(-1).mean(-1)
    
  This produced EXACTLY 0.0 entropy for 4,000+ steps, causing:
    - gate_score to permanently lock at 0.1192 (the sigmoid floor)
    - Arms 1-3 receiving only 5% gradient flow (trickle-charge floor)
    - The Cognitive Bloom never occurring despite the Cognitive Cocktail shock

  ROOT CAUSE (Validated by DeepThink): Mamba SSMs are ODE-based recurrent
  systems. Once the Phase 2 SFT training converged on the GSM8K formatting,
  the recurrent state transitions became so deterministic that token probability
  distributions collapsed to Dirac delta functions. Even in float32, the softmax
  probability of the predicted token was mathematically 1.0, and all other tokens
  were 0.0. The entropy formula returned exactly 0.0 — not approximately zero,
  literally zero — with no possibility of organically rising above this ceiling
  regardless of how much the Thalamic Primer's weights grew.

  This is fundamentally different from Transformer behavior, where softmax
  attention matrices inherently distribute probability mass across all sequence
  positions, providing a natural non-zero entropy floor.

  FINDING: This represents a previously undocumented failure mode in zero-init
  adapter grafting within SSM architectures. The standard LoRA/adapter assumption
  ("entropy will rise as the adapter weights grow") does not hold for converged SSMs
  because the ODE fixed-point attractor is too strong to be perturbed by small
  weight perturbations in the pre-backbone layers.

2.3 — THE PRIMER ACTIVATION MAGNITUDE FIX (Step 26,200)
  The entropy gate was replaced with a "Primer Activation Magnitude" routing signal:
  
    primer_out = self.thalamic_primer(orig_embs)
    primer_delta = (primer_out - orig_embs).norm(dim=-1).mean()
    routing_signal = primer_delta.detach()
    raw_gate_score = torch.sigmoid(routing_signal * 10.0 - 1.0)
  
  PHYSICS: This signal directly measures HOW MUCH the Thalamic Primer is
  transforming the input embeddings. At zero-initialization, primer_out ≡ orig_embs
  (identity), so primer_delta = 0.0 and gate_score = sigmoid(-1.0) = 0.27 (lower
  floor). As the Primer weights grow from 4,000 steps of gradient flow, the delta
  increases organically. Once primer_delta reaches ~0.1 nats, gate_score crosses
  0.5 (50% MIMO activation). This signal is immune to the SSM glass ceiling because
  it measures weight-space geometry, not probability-space entropy.

  Additionally, the Primer output is now blended into the residual stream:
    x = orig_embs + primer_out * 0.1
  
  This 10% blend injects the Primer's temporal context into the main processing
  stream while protecting the 24-layer backbone from abrupt perturbation.

SECTION 9: RESEARCH NOTES FOR DEEPTHINK REVIEW
================================================================================

NOTE 1: THE SSM ENTROPY GLASS CEILING
  The inability of a converged Mamba SSM to produce non-zero entropy from
  pre-backbone logit projections appears to be a fundamental property of the
  SSM fixed-point attractor mechanism. Unlike Transformer attention, which
  inherently spreads probability mass across all positions, the SSM's gated
  recurrence converges to a deterministic state trajectory after sufficient
  training. The practical implication is that all entropy-based routing mechanisms
  (including industry standard MoE routing by input uncertainty) may require
  redesign for SSM-based architectures. Primer Activation Magnitude is proposed
  as an SSM-specific alternative routing signal.

NOTE 2: TRICKLE-CHARGE AS SPARSE MOE SOLUTION
  The 5% gradient floor (torch.clamp, min=0.05) represents an extremely
  low-overhead solution to the expert atrophy problem that typically requires
  computationally expensive auxiliary load-balancing loss terms in large MoE
  systems (e.g., the Switch Transformer's z-loss, or the load-balancing loss
  in Mixtral). The biological framing as "life support" rather than "load balancing"
  led to a simpler, more effective solution. Warrants formal ablation study.

NOTE 3: ZERO-INIT GRAFT VIABILITY IN SSMs
  The zero-initialization strategy (init.zeros_ on output projection) successfully
  preserved 43,000+ steps of pre-training and 3,600 steps of SFT formatting
  through the Phase 3 graft operation. The Phase 2 weights were NOT disrupted.
  This validates zero-init grafting as a viable technique for SSM architectural
  surgery, but requires the Primer Activation Magnitude gate (Note 1) rather than
  entropy-based routing to function correctly.

NOTE 4: SMOOTH BLOOM VS. VIOLENT BLOOM
  The absence of the predicted violent loss spike (5-8) during the Bloom, instead
  producing a smooth gate-opening (loss stayed 1.1-2.1), is attributable to the
  Trickle-Charge Patch maintaining 5% gradient warmth in the dormant arms. This
  finding suggests that MoE expert re-activation after dormancy can be made
  adiabatic (smooth/gradual) rather than non-adiabatic (explosive) by maintaining
  minimal basal gradient flow during the dormancy period. The analogy to biological
  neural plasticity (synaptic warmth preventing LTP degradation) is apt.
